# 💳 Pricing Cards

A modern, responsive **Pricing Cards UI** built with HTML5 and CSS3.

This project presents multiple subscription plans in a clean dark-themed interface. It includes pricing information, feature comparisons, a highlighted popular plan, call-to-action buttons, and a customer testimonial section.

The project is designed as a front-end pricing component that can be integrated into SaaS websites, product landing pages, business websites, and other web applications.

---

## ✨ Features

- 💳 Three pricing plans
- 🚀 Basic plan
- 💎 Pro plan
- 🏢 Enterprise plan
- ⭐ "Most Popular" plan highlight
- 📋 Feature comparison
- ✅ Included features
- ❌ Unavailable features
- 💰 Monthly pricing display
- 🚀 Get Started buttons
- 💬 Customer testimonial section
- 👤 Customer profile
- 🎨 Modern dark UI
- 🟢 Green accent color
- ✨ Gradient heading
- 🖱️ Hover animations
- 📈 Card elevation effects
- 💫 Animated Pro button
- 📱 Responsive layout
- ⚡ Lightweight implementation
- 🚫 No JavaScript required
- 🚫 No frameworks required
